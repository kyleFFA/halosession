# Parked design notes

These are future ideas, not implemented changes or authorization to modify the accepted build. Repository/source preparation remains the current work.

## Refine the main Session skin before optional skins

- Make the Halo ring more front-facing and truly circular while retaining a visible metallic rim and inner surface.
- Keep the radial wheel concentric inside the ring, with the same shared position and scale behavior.
- Preserve the clouds. Consider two slowly moving transparent cloud layers, with a static option and measured rendering cost before choosing animation.
- Keep the center mostly opaque while allowing a little game geometry through. Use a steady translucent backing beneath the clouds so label readability stays consistent.
- Later skins may change artwork, colors and cloud treatment while preserving familiar control placement.

The current static artwork, geometry, controller behavior and accepted binaries remain unchanged.
